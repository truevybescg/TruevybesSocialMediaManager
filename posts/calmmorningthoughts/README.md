# @calmmorningthoughts — 10-Day Bhagavad Gita Content Calendar

A 10-day content pack for growing the **calmmorningthoughts** Instagram handle:
daily Hinglish (Hindi + English) voiceover scripts rooted in the Bhagavad Gita,
paired with soothing Krishna-in-nature background briefs, captions, hashtags,
and posting guidance.

## How to use this folder

1. Open `day-01-*.md` through `day-10-*.md` in order — one file = one Reel.
2. Read the **Script** section slowly into your mic (it's written for a
   60–90 second voiceover, with natural pause points marked `//`).
3. Use the **Background Visual Brief** to pick or generate your video loop.
4. Copy the **Caption** + **Hashtags** straight into the Instagram post box.
5. Post at the suggested time — consistency is what the algorithm and the
   "calm morning" brand promise both reward.

## Voice-over delivery tips

- Speak 20% slower than normal conversation — "calm morning" content lives or
  dies on pacing. Let the Sanskrit line breathe before you translate it.
- Use the `//` marks in each script as breath/pause points.
- Record in a quiet room; a soft room-tone / ambient nature bed under your
  voice (see Music suggestion in each file) hides small mic imperfections.
- Say the Sanskrit shloka once cleanly, then immediately give the simple
  Hinglish meaning — don't assume the viewer reads Devanagari on-screen fast.

## Sourcing the Krishna / outdoor background footage

I can't attach an actual video file here, but every day file gives you a
precise **Background Visual Brief** you can execute three ways:

1. **Royalty-free stock loops** — search these exact terms on Pexels,
   Pixabay, or Mixkit (all have free video sections): "Yamuna river sunrise",
   "peacock feather close up", "banyan tree sunlight", "temple bells slow motion",
   "lotus pond morning mist", "flute silhouette sunset". Layer 2–3 clips with
   soft crossfades behind your voiceover text.
2. **AI-generated original Krishna artwork** (recommended — avoids any
   copyright issue with existing devotional art): generate a still with
   Midjourney/Leonardo/Nano Banana using the "Image Prompt" given in each
   file, then animate it into a slow-drifting loop with an image-to-video
   tool (Kling, Runway, Pika). This gives you a fully original, attractive,
   soothing Krishna-outdoors visual every day without licensing risk.
3. **Licensed devotional art** — if you'd rather use traditional Krishna
   paintings, license them properly (Adobe Stock / iStock devotional
   collections) rather than pulling unlicensed images off Google/Pinterest,
   since Meta and rights-holders do issue takedowns on those.

## Music

Keep it consistent across all 10 days so it becomes part of the "calm
morning thoughts" brand sound — a single soft bansuri (flute) + tanpura drone
loop at low volume (–20 dB under your voice) works for the whole series.
Use Instagram's own royalty-free audio library ("Meditation Flute", "Peaceful
Sitar" type tracks) so Reels don't get muted for copyright.

## Caption / growth mechanics used across all 10 days

- **Hook line first** — the first 6–8 words appear before "more", so each
  caption opens with the punchiest line, not the shloka.
- **One clear CTA** — alternates between "Save this for tomorrow morning 🔖",
  "Follow for daily Gita wisdom 🙏", and "Tell me in the comments which line
  hit you today 👇" so it doesn't feel repetitive across the week.
- **Hashtag mix** — each post uses ~12–15 tags blending broad
  (#BhagavadGita #KrishnaWisdom) with niche/low-competition
  (#GitaInHindi #MorningMotivationIndia) tags for better discovery odds as a
  smaller account.

## Suggested posting time

6:00–7:30 AM IST daily. It matches the "calm morning" promise literally, and
Instagram Reels from wellness/spiritual accounts in India consistently see
the strongest early save/share behavior in that window as people scroll
before starting their day.
