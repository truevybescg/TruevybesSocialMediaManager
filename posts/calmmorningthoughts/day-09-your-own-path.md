# Day 9 — Walk Your Own Path, Stop Comparing

**Theme:** Swadharma — your unique purpose
**Gita Reference:** Chapter 3, Verse 35

## Shloka

> श्रेयान्स्वधर्मो विगुणः परधर्मात्स्वनुष्ठितात्।
> स्वधर्मे निधनं श्रेयः परधर्मो भयावहः॥

**Transliteration:** Shreyan sva-dharmo vigunah, para-dharmat
svanushthitat, Svadharme nidhanam shreyah, para-dharmo bhayavahah.

**Simple meaning:** Apna dharma, chahe kamzor ho, doosre ke perfect
dharma se behtar hai. Apne raaste par chalte hue rukna bhi, kisi aur ka
raasta chalne se behtar hai. Doosre ka raasta khatarnaak hota hai.

## Script (voiceover, ~60–75 sec)

Instagram khol ke, // kisi aur ki life dekh ke, // apni life choti lagne
lagti hai. // Ye feeling shayad sabse common problem hai aaj ke time
mein.

Krishna ne iska jawab bhi diya tha, // Arjun se — // "Shreyan sva-dharmo
vigunah, para-dharmat svanushthitat" — // apna raasta, chahe woh imperfect
ho, // kisi aur ke perfect raaste se behtar hai.

Har insaan ka apna path hota hai, // apni speed hoti hai, // apna
"dharma" hota hai. // Jo cheez kisi aur ke liye kaam karti hai, // zaroori
nahi tumhare liye bhi kare.

Jab tum apna path chhod ke doosre ka path follow karte ho — // sirf isliye
ki woh "achha lag raha hai" — // tab tum apni asli takat kho dete ho.

Aaj comparison band karo. // Apni journey ko dekho, // apni speed ko
respect do. // Tumhara imperfect raasta, // kisi aur ke perfect copy se
kahin zyada real hai.
