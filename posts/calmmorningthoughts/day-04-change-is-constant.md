# Day 4 — Change Is The Only Constant

**Theme:** New clothes for the soul
**Gita Reference:** Chapter 2, Verse 22

## Shloka

> वासांसि जीर्णानि यथा विहाय नवानि गृह्णाति नरोऽपराणि।
> तथा शरीराणि विहाय जीर्णान्यन्यानि संयाति नवानि देही॥

**Transliteration:** Vasamsi jirnani yatha vihaya, navani grihnati naro
'parani, Tatha sharirani vihaya jirnany, anyani samyati navani dehi.

**Simple meaning:** Jaise insaan purane kapde utaar ke naye pehen leta
hai, waise hi aatma purane sharir ko chhod ke naya sharir dhaaran karti
hai.

## Script (voiceover, ~60–75 sec)

Naukri chhoot gayi, // relationship khatam ho gaya, // ghar badal gaya —
har baar hum sochte hain "ab kya hoga?"

Krishna ek simple example dete hain // "Vasamsi jirnani yatha vihaya" —
jaise tum purane, phate hue kapde utaar ke naye pehente ho, // waise hi
aatma bhi purane sharir ko chhod ke naya lene chalti hai.

Change dukh nahi hai — // change hi jeevan hai. // Jo cheez purani ho
chuki hai, use pakad ke rakhna, // wahi asli dukh ka karan hai.

Toh agli baar jab kuch khatam ho — // ek job, ek phase, ek rishta — //
usse "ant" mat samjho. // Samjho ki ek purana kapda utar raha hai, //
aur kuch naya, better tumhara wait kar raha hai.

Badlaav se daro mat. // Badlaav hi Krishna ka sabse pehla sabak hai.

## Caption

Kuch khatam hone se dar lagta hai? Ye ek line sab badal degi. 🌱

Chapter 2, Verse 22 — jaise purane kapde utaar ke naye pehente ho, waise
hi jeevan bhi ek phase chhod ke naya shuru karta hai. Change hi jeevan
hai.
