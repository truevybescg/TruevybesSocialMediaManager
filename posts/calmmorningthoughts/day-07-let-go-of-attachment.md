# Day 7 — Attachment Is The Root Of Anger

**Theme:** Letting go to find peace
**Gita Reference:** Chapter 2, Verses 62–63

## Shloka

> ध्यायतो विषयान्पुंसः सङ्गस्तेषूपजायते।
> सङ्गात्संजायते कामः कामात्क्रोधोऽभिजायते॥

**Transliteration:** Dhyayato vishayan pumsah, sangas teshu upajayate,
Sangat sanjayate kamah, kamat krodho 'bhijayate.

**Simple meaning:** Jab hum kisi cheez ke baare mein baar-baar sochte
hain, uske saath attachment ban jaata hai. Attachment se desire paida
hoti hai, aur desire poori na ho toh crodh (anger) paida hota hai.

## Script (voiceover, ~60–75 sec)

Gussa kahan se aata hai? // Ye sawaal Krishna ne hazaaron saal pehle hi
solve kar diya tha.

"Dhyayato vishayan pumsah, sangas teshu upajayate" — // jab hum kisi
cheez ke baare mein baar-baar sochte rehte hain, // uske saath ek
attachment ban jaata hai.

Fir woh attachment desire banta hai — // "mujhe ye chahiye hi chahiye."
// Aur jab woh desire poori nahi hoti, // tab paida hota hai gussa.

Socho — // last time jab tumhe bahut gussa aaya tha, // uske peeche
kahin na kahin ek expectation thi, // ek attachment tha kisi cheez se, ya
kisi se.

Iska solution ye nahi ki kuch chaho hi mat. // Solution hai — // apne
attachment ko pehchano. // Jab tum jaan jaate ho "main iss cheez se bahut
juda hua hoon," // wahi awareness tumhe control deti hai apne reaction
par.

Gussa aane se pehle, // ek pal ruko, // aur poochho — "main kis cheez se
itna attached hoon?"
