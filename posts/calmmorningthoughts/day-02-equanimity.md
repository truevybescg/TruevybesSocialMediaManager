# Day 2 — Sukh-Dukh Dono Aane-Jaane Wale Hain

**Theme:** Equanimity in pleasure and pain
**Gita Reference:** Chapter 2, Verses 14–15

## Shloka

> मात्रास्पर्शास्तु कौन्तेय शीतोष्णसुखदुःखदाः।
> आगमापायिनोऽनित्यास्तांस्तितिक्षस्व भारत॥

**Transliteration:** Matra-sparshastu kaunteya, sheetoshna-sukha-duhkhadah,
Agamapayino 'nityas, tans-titikshasva bharata.

**Simple meaning:** Sardi-garmi, sukh-dukh — ye sab sirf temporary
sensations hain, jo aate hain aur chale jaate hain. Inhe sehna seekho,
inme khoye mat raho.

## Script (voiceover, ~60–75 sec)

Aaj achha din hai toh khushi, // kal kharab din hai toh dukh — hum sab
iss cycle mein phanse hue hain.

Lekin Krishna kehte hain Arjun se // "Matra-sparshastu kaunteya" — ye
sukh aur dukh, ye sardi aur garmi jaisi feelings hain. // Ye aati hain,
aur chali jaati hain. Inka koi permanent address nahi hai tumhare andar.

Jab tak hum har emotion ko "main hi hoon" samajhte rahenge, // hum uske
saath uthenge aur girenge. // Lekin jis din hum ye samajh jaate hain ki
"ye bhi guzar jayega" — // wahi din hum sthir hona seekhte hain.

Toh agli baar jab koi mushkil pal aaye, // ya koi bahut acha pal bhi aaye
— // dono ko yaad rakho, ye temporary hai. // Tum inse bade ho.

Sthirta hi asli shanti hai.

## Caption

"Ye bhi guzar jayega" — ye sirf ek line nahi, Gita ka gehra gyaan hai. 🌊

Chapter 2, Verse 14-15 — sukh aur dukh dono temporary sensations hain,
jaise sardi-garmi. Inhe sehna seekho, khud ko inse bada samjho.

Follow for daily Gita wisdom 🙏 — kal ek aur sabak.
