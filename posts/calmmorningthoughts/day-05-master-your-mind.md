# Day 5 — You Are Your Own Best Friend Or Worst Enemy

**Theme:** Self-mastery
**Gita Reference:** Chapter 6, Verses 5–6

## Shloka

> उद्धरेदात्मनात्मानं नात्मानमवसादयेत्।
> आत्मैव ह्यात्मनो बन्धुरात्मैव रिपुरात्मनः॥

**Transliteration:** Uddhared atmanatmanam, natmanam avasadayet,
Atmaiva hyatmano bandhur, atmaiva ripuratmanah.

**Simple meaning:** Khud ko khud hi uthao, khud ko kabhi neeche mat
giro. Kyunki mann hi tumhara sabse acha dost hai, aur mann hi tumhara
sabse bada dushman ban sakta hai.

## Script (voiceover, ~60–75 sec)

Kabhi socha hai, // sabse zyada tum apne aap se hi baat karte ho —
subah uthte hi, so ne se pehle, // ek continuous internal conversation
chalti rehti hai.

Krishna kehte hain // "Atmaiva hyatmano bandhur, atmaiva ripuratmanah" —
tumhara mann hi tumhara sabse bada dost hai, // aur wahi mann tumhara
sabse bada dushman bhi ban sakta hai.

Jo log khud se pyaar se baat karte hain, // khud ko motivate karte hain
— // unka mann dost ban jaata hai. // Jo log khud ko har waqt criticize
karte hain, // doubt karte hain — // unka mann hi unka sabse bada dushman
ban jaata hai.

Toh aaj ek choice karo — // jab bhi khud se baat karo, // ek achhe dost
ki tarah baat karo, na ki ek critic ki tarah.

Tumhari sabse badi jung, // bahar nahi, // andar hai.

## Caption

Tumhara sabse bada dushman kaun hai? Shayad tum khud. 🪞

Chapter 6, Verse 5-6 — mann hi dost hai, mann hi dushman. Khud se ek
achhe dost ki tarah baat karo.
