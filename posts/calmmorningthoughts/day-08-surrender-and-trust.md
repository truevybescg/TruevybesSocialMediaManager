# Day 8 — Surrender Fully, Stop Carrying The Whole World Alone

**Theme:** Trust the process
**Gita Reference:** Chapter 18, Verse 66

## Shloka

> सर्वधर्मान्परित्यज्य मामेकं शरणं व्रज।
> अहं त्वा सर्वपापेभ्यो मोक्षयिष्यामि मा शुचः॥

**Transliteration:** Sarva-dharman parityajya, mam ekam sharanam vraja,
Aham tva sarva-papebhyo, mokshayishyami ma suchah.

**Simple meaning:** Sab kuch chhod ke, sirf mujh par bharosa karo. Main
tumhe har paap, har bojh se mukt kar dunga. Chinta mat karo.

## Script (voiceover, ~60–75 sec)

Kabhi aisa laga hai ki sab kuch akele sambhalna pad raha hai? // Ghar,
kaam, rishtey, khud ke expectations — // jaise poori duniya tumhare
kandhon par hai.

Iss thakan ke jawab mein, // Krishna ne Arjun se kaha // "Sarva-dharman
parityajya, mam ekam sharanam vraja" — // sab kuch chhod ke, sirf mujh
par shraddha rakho. // "Aham tva sarva-papebhyo mokshayishyami, ma
suchah" — // main tumhe har bojh se mukt kar dunga, chinta mat karo.

Iska matlab yeh nahi ki tum koshish karna chhod do. // Iska matlab hai —
// apna best do, // aur baaki sab ek higher shakti par, ek universe ke
process par chhod do.

Har cheez tumhe akele control karni hai — // ye ek bhram hai. // Kabhi
kabhi sabse bada strength hota hai — // haath jodna, aur kehna, "main
apna best de raha hoon, baaki tumhare bharose."

Aaj thoda bhaar utaar do. // Sab kuch tumhe akele nahi karna.
