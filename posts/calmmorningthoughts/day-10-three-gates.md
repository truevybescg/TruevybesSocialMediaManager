# Day 10 — Kaam, Krodh, Lobh: The 3 Gates To Self-Destruction

**Theme:** Choosing a calm, clear mind (week closer)
**Gita Reference:** Chapter 16, Verse 21

## Shloka

> त्रिविधं नरकस्येदं द्वारं नाशनमात्मनः।
> कामः क्रोधस्तथा लोभस्तस्मादेतत्त्रयं त्यजेत्॥

**Transliteration:** Tri-vidham narakasyedam, dvaram nashanam atmanah,
Kamah krodhas tatha lobhas, tasmad etat trayam tyajet.

**Simple meaning:** Kaam (excessive desire), krodh (anger), aur lobh
(greed) — ye teen darwaze hain jo insaan ko andar se khatam kar dete
hain. Inhe chhod dena chahiye.

## Script (voiceover, ~75–90 sec)

Iss hafte humne bahut kuch seekha — // aaj Krishna hume ek simple, seedhi
si baat batate hain, // jo puri Gita ka nichod hai.

"Tri-vidham narakasyedam dvaram, nashanam atmanah" — // teen darwaze
hain, jo tumhe andar se khatam kar dete hain. // "Kamah krodhas tatha
lobhas" — // pehla, // Kaam — jab desire itni badh jaaye ki tum kabhi
santusht hi na ho. // Dusra, // Krodh — jab gussa tumhare decisions
control karne lage. // Teesra, // Lobh — jab lalach itna ho ki jitna bhi
mile, kam lage.

Ye teeno, // ek jaisa pattern follow karte hain — // ye chhote shuru hote
hain, aur dheere dheere puri shanti khaa jaate hain.

Iss hafte hum ne dekha — // apna kaam karo, phal chhod do // sukh-dukh
temporary hain // aatma amar hai // change se mat daro // khud ke best
dost bano // senses ko control karo // attachment pehchano // pura bharosa
rakho // aur apna raasta chuno.

Sab kuch ek jagah aata hai — // agar tum in teen darwazon se bachte ho —
kaam, krodh, lobh — // toh baaki sab apne aap saral ho jaata hai.

Kal se phir milte hain, // ek naye shant subah ke saath. // Namaste. 🙏
